# GitHub 同步存储

把 Tau 的笔记、对话和附件同步到你自己的 GitHub 仓库里。换电脑或在电脑与手机之间切换时，都能拿到同一份资料库数据。

## 开始使用

1. 先在 GitHub 上建好仓库和分支，建议单独建一个**私有**仓库。
2. 在 GitHub 生成一个访问令牌，给它这个仓库的内容读写权限。
3. 在插件中心安装「GitHub 同步存储」，再到插件页的「已安装」里打开开关。
4. 打开插件详情的「设置」，填写「访问令牌」，再选择「仓库」和「分支」（「仓库所有者」留空则使用令牌所属账号，「目录」可留空）。
5. 保存并测试连接后，到「设置 → 同步」选用此服务，即可检查状态、上传、下载或开启自动同步。保存配置不会自动切换当前同步服务。

## 常见问题

**提示找不到仓库或分支？** 插件不会帮你新建，请先在 GitHub 上建好，并确认访问令牌有这个仓库的读写权限。

**附件很多、很大时合适吗？** 不太合适。GitHub 对单个文件的大小和访问频率都有限制，附件特别多或特别大时，建议改用 S3、阿里云 OSS 等对象存储。

**能和别的资料库共用同一个位置吗？** 不要。每个资料库请使用单独的存储位置（可以用「目录」区分），否则数据会互相覆盖。

**停用插件会删掉数据吗？** 不会。你的配置和已经同步上去的数据都会保留，重新启用就能接着用。正在同步时不能停用或卸载插件，等同步结束再操作。

## 小提醒

- 支持电脑与手机；如果同时装了资源上传插件，两边的账号分开填写，互不影响。
- 访问令牌相当于你的 GitHub 密码，不要发给别人，也不要贴在截图或问题描述里。
