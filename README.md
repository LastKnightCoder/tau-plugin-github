# GitHub 同步存储

把 Tau 的笔记、对话、附件同步到你自己的 GitHub 仓库里。换电脑或多台设备之间，都能拿到同一份数据。

## 开始使用

1. 先在 GitHub 上建好一个仓库和分支，建议单独建一个**私有**仓库来放。
2. 在 GitHub 生成一个访问令牌，给它这个仓库的内容读写权限。
3. 在插件中心安装「GitHub 同步存储」，再到插件页的「已安装」里打开它的开关（不用重启）。然后打开「设置 → 同步」选择它，填写仓库所有者、仓库名、分支和访问令牌；路径前缀可以不填。
4. 保存后，就可以用检查、上传、下载和自动同步了，用法和其他同步方式一样。

## 常见问题

**提示找不到仓库或分支？** 插件不会帮你新建，请先在 GitHub 上建好，并确认令牌有这个仓库的读写权限。

**附件很多、很大时合适吗？** 不太合适。GitHub 对单个文件的大小和访问频率都有限制，附件特别多或特别大时，建议改用 S3、OSS 等对象存储。

**能和别的知识库共用同一个位置吗？** 不要。每个知识库请用单独的存储位置（可以用「路径前缀」区分），否则数据会互相覆盖。

**停用插件会删掉数据吗？** 不会。你的配置和已经同步上去的数据都会保留，重新启用就能接着用。正在同步时不能停用或卸载插件，等同步结束再操作。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 访问令牌相当于你的 GitHub 密码，不要发给别人，也不要贴在截图或问题描述里。
