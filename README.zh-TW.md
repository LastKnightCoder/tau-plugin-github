# GitHub 同步儲存

將 Tau 的筆記、對話與附件同步至你自己的 GitHub 儲存庫。更換電腦或在電腦與手機之間切換時，都能取得同一份資料庫資料。

## 開始使用

1. 先在 GitHub 上建立好儲存庫與分支，建議單獨建立一個**私人**儲存庫。
2. 在 GitHub 產生一組存取權杖，並授予該儲存庫的內容讀寫權限。
3. 在外掛中心安裝「GitHub 同步儲存」，再到外掛頁的「已安裝」裡開啟開關。
4. 開啟外掛詳情的「設定」，填寫「存取權杖」，再選擇「儲存庫」與「分支」（「儲存庫擁有者」留空則使用權杖所屬帳號，「目錄」可留空）。
5. 儲存並測試連線後，前往「設定 → 同步」選用此服務，即可檢查狀態、上傳、下載或開啟自動同步。儲存設定不會自動切換目前使用的同步服務。

## 常見問題

**提示找不到儲存庫或分支？** 外掛不會自動建立，請先在 GitHub 上建好，並確認存取權杖具備該儲存庫的讀寫權限。

**附件很多或很大時適合使用嗎？** 不太適合。GitHub 對單一檔案大小與存取頻率皆有限制，若附件數量多或體積較大，建議改用 S3、阿里雲 OSS 等物件儲存服務。

**可以和其他資料庫共用同一個儲存位置嗎？** 不要。請為每個資料庫使用獨立的儲存位置（可透過「目錄」區分），否則資料會互相覆蓋。

**停用外掛會刪除資料嗎？** 不會。你的設定與已同步的資料都會保留，重新啟用就能繼續使用。正在同步期間無法停用或解除安裝外掛，請待同步完成後再操作。

## 小提醒

- 支援電腦與手機；如果同時安裝了資源上傳外掛，兩邊的帳號分開填寫，互不影響。
- 存取權杖相當於你的 GitHub 密碼，不要發給別人，也不要貼在截圖或問題描述裡。
